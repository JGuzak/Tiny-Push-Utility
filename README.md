# Tiny Push Utility

A utility for managing `Tiny Sound Systems` apps and tools that run on Push 3 Standalone.

*NOTE: This tool is currently in beta.*

<!-- ![Tiny Push Utility demo video]() -->

## FAQ

*How can I download this tool?*

Download the latest version and user manual from the [releases](https://github.com/JGuzak/Tiny-Push-Utility/releases) page.

*I don't have Push Standalone but I do have a Push controller, can I still use this tool?*

No, this tool only works with Push 3 Standalone devices. Push 3 controllers and previous generations of Push are controllers for PC and Mac. This tool is specifically for managing `Tiny Sound Systems` apps on Push 3 Standalone.

*Can I navigate the file system on Push Standalone from this app?*

Not as of now. This tool is intended to be simple and light weight.

*How can I submit bugs or report issues?*

Please follow instructions outlined in the `User Manual`.
